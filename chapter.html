Differential Calculus

Learn the fundamentals of differentiation and its applications in solving real-world problems.

Introduction to Differentiation

Differentiation is a fundamental concept in calculus that deals with rates of change. It allows us to find the gradient of a curve at any point, which has numerous applications in physics, engineering, economics, and other fields.

The Derivative

The derivative of a function f(x) is denoted as f'(x) or dy/dx. It represents the rate of change of y with respect to x.

f'(x) = limh→0 [f(x+h) - f(x)] / h

Basic Rules of Differentiation

Power Rule

If f(x) = xn, then f'(x) = nxn-1

Example: If f(x) = x3, then f'(x) = 3x2

Sum Rule

The derivative of a sum is the sum of the derivatives:

d/dx [f(x) + g(x)] = f'(x) + g'(x)

Product Rule

For the product of two functions:

d/dx [f(x)g(x)] = f'(x)g(x) + f(x)g'(x)

Quotient Rule

For the quotient of two functions:

d/dx [f(x)/g(x)] = [f'(x)g(x) - f(x)g'(x)] / [g(x)]2

Applications of Differentiation

  • Finding Tangents: The derivative gives the slope of the tangent line at any point on a curve.
  • Optimization: Finding maximum and minimum values of functions.
  • Related Rates: Solving problems where multiple quantities change together.
  • Curve Sketching: Analyzing the behavior of functions.

Practice Exercise

Differentiate the following function:

f(x) = 3x4 - 2x3 + 5x - 7

Solution: f'(x) = 12x3 - 6x2 + 5

Chapter Quiz

Code Example


def differentiate_power_function(x, n):
    """
    Differentiate x^n using the power rule
    """
    return n * x ** (n - 1)

# Example usage
result = differentiate_power_function(2, 3)  # Should return 12
print(f"Derivative at x=2 for x^3 is: {result}")
